3. PROJECT DESCRIPTION & SUMMARY
--------------------------------------------------------------------------------
Campus FMS is an enterprise-grade facility operations, technician dispatch, and
maintenance request management system designed for academic and enterprise campuses.

Key Architectural Capabilities:
- Four Isolated Consoles:
    1. Student & Staff Portal (/portal) - Report issues, live SLA countdowns, 1-5 star ratings
    2. Technician Console (/technician) - Task queue, repair logs, spare part costs in INR (₹)
    3. Facility Admin (/admin) - Skill-based dispatch, emergency escalation, audit logs
    4. Executive Management (/management) - Read-only BI dashboard, SLA % and cost analytics
- Full-Stack Technology:
    Backend  : Python 3.10+, Flask 3.0 REST API
    Frontend : Modern Vanilla HTML5, CSS3, ES6+ JavaScript, Chart.js
    Database : MySQL 8.4 (Hosted on Railway)
    Hosting  : Vercel Serverless Edge Runtime
- Defense-in-Depth Security:
    Server-side RBAC (@role_required), cryptographic CSRF protection, 15-minute
    brute-force account lockout, and object-level IDOR prevention.
